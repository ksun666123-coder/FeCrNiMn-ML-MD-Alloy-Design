# Interatomic potential

This directory includes the Fe-Ni-Cr-Mn EAM/alloy potential used by the LAMMPS calculations:

`FeNiCrMn_EAM_Daramola2022.eam.alloy`

The potential-file header identifies the source as:

A. Daramola et al., *Computational Materials Science* 203 (2022) 111165.

The setfl element order in the supplied file is:

`Fe Ni Cr Mn`

Keep the filename unchanged because the public scripts reference this name by default.
