# Code manifest

Included files are source code, configuration notes, and repository metadata only.

No manuscript datasets, MD numerical outputs, stress-strain data, SHAP CSV files, or trajectory files are included.

The preliminary 150-candidate generation script is intentionally not included in this public package because the submitted manuscript describes the final 100-composition modeling dataset rather than that preliminary candidate-pool step. The original script should be retained privately for research records.
